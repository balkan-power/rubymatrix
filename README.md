# RubyMatrix
Matrix CLI program written in Ruby.

## Prerequisites
### Windows
You may run from source or download the executable listed under "Releases" here.
### Linux
You must have Ruby installed on your machine to run this program from source.<br>
(Linux binary coming soon?)
## Usage
### Run by using
> ruby rubymatrix.rb
or<br>
> rubymatrix.exe
on Windows.
### Run with different arguments
> ruby rubymatrix.rb -[argument]
### Arguments:
- -c (use half-width kana)
- -C [colour]
- -d [delay]
- -h (help)
- -v (show version)

You can use multiple arguments together to change the appearance of your matrix rainfall.
